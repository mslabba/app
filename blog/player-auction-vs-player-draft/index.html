Player Auction vs Player Draft: What's the Difference?

14 October 2026

The difference is how players are allocated. In a player auction, teams bid for each player and spend from a fixed purse, so any team can go after any player if it is willing to pay. In a player draft, teams take turns picking players in an order set beforehand, and no money changes hands. Auctions reward budget strategy; drafts reward pick order and preparation.

How does a player draft work?

Teams are given a pick order before the event. Team one picks a player, then team two, and so on. In a snake draft, the order reverses each round so the team that picked last in round one picks first in round two. The organiser's job is to keep the order honest and the roster rules clear.

How does a player auction work?

Players come up one at a time with a base price. Owners bid, a countdown runs, and the highest bidder wins. The price comes off that team's purse. Because every team has a limited purse, spending big on one player means less for the rest of the squad. See How to Conduct a Cricket Player Auction for the full auction-day sequence.

Auction vs draft at a glance

Player auction Player draft
Allocation Highest bid wins Teams pick in order
Constraint Team purse and squad size Pick order and roster rules
Can two teams compete for one player? Yes, by bidding No, first to pick takes them
Event feel Live, competitive, spectator-friendly Quicker, quieter
Setup work Purses, base prices, categories Pick order, roster rules
Main risk Teams overspend early Pick-order disputes

Which is fairer, an auction or a draft?

Both can be fair if the rules are published in advance. A draft is fair if the order is set transparently, for example by lottery or reverse standings. An auction is fair if every team has the same purse (or a published reason it does not), base prices are set before the day, and everyone can see the current bid and each team's remaining purse.

When should you choose an auction?

Choose an auction when you want team owners to make real trade-offs, when the event itself is part of the attraction, and when you have named owners willing to manage a budget. Local cricket leagues, corporate tournaments and school or college competitions often use auctions for exactly this reason.

When is a draft the better choice?

A draft suits small groups, informal leagues, or events with no owners and no appetite for budgets. It is also easier to run without any software.

Can you mix the two?

Some leagues do: they retain a few players or assign icons by rule, then auction the rest. If you mix formats, write down which players go through which route and how retained players affect the purse.

Frequently asked questions

What is the main difference between an auction and a draft?

In an auction, teams bid for players against a purse. In a draft, teams pick players in a pre-set order without bidding.

Is a snake draft the same as an auction?

No. A snake draft reverses the pick order each round but still uses picks, not bids or budgets.

Which format is better for a cricket league?

Many local cricket leagues prefer auctions because owners compete for players and the event is engaging to watch. A draft is simpler if you have no team owners or budgets.

Can a league combine retention and an auction?

Yes, if the rules say which players are retained and how that affects each team's purse.
